# ozon · OZON 入局自测

**7 道题，满分 100，判断你适不适合做俄罗斯 OZON 跨境店。**

装到豆包、WorkBuddy、Claude Code、Codex 等支持 Skills 的 Agent 后，在对话里直接说「帮我测一下能不能做 OZON」，它会一道一道问你，最后给你分数、结论、最弱项的补法、回款时间和开店材料清单。

## 安装

**方式一：在 Agent 对话里说一句**

```text
安装 jibin-chuhai 的 ozon
```

**方式二：命令行**

```bash
npx -y skills add jibin-chuhai/ozon -g --all
```

装好后技能显示为 **ozon**，后面跟着中文说明：OZON 入局自测：问 7 道题打个分……

## 它问什么

| # | 维度 | 分值 |
|---|---|---|
| 1 | 电商经验（含国内电商） | 18 |
| 2 | 供应链资源 | 16 |
| 3 | 擅长的产品 | 10 |
| 4 | 可动用现金 | 25 |
| 5 | 每天可投入时间 | 8 |
| 6 | 电脑基础操作 | 8 |
| 7 | 兼职还是全职 | 15 |

另外两问不计分但是硬门槛：有没有企业营业执照、有没有同名收款账户。

## 它给什么

- **分数**：七项明细相加，满分 100
- **结论**：可以做 / 补最弱一项 / 先补两项 / 别投钱
- **最弱项**：哪项拖后腿，本周具体怎么补
- **回款时间**：运输 13–35 天 → T+15 保护期 → 半月结打款 → 银行 1–3 天，实际周转约 45–70 天
- **材料清单**：企业营业执照（自然人独资，个体户不支持）、法人身份证、手机号、邮箱、同名收款账户、EAC（受管类目）

## 三条硬覆盖

1. 无企业执照 / 无同名收款 → **现在开不了店**
2. 现金 < 5000 → **现在别投钱**
3. 已辞职无收入 → **降档**，并给三条风控提示

## 为什么资金占 25 分

钱付给供应商是立刻的，回来要 45–70 天。资金不足的真实问题不是「不够进货」，而是「撑不过这两个月」。

## 它也有一份网页版

`skills/ozon/assets/ozon-selfcheck.html` 是可视化版本，手机浏览器打开就能点，不联网、不上传数据。适合发给不想装技能的人。

## 边界

不承诺收益、不代注册、不垫资、不做品类排行榜。规则与费率以后台当期值为准。
