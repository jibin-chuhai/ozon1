# 评分表（完整版）

满分 100，七项相加，不设加权。

| 维度 | 分值 | 说明 |
|---|---|---|
| 电商经验（含国内） | 18 | 会不会看数据、会不会算账 |
| 供应链资源 | 16 | 能不能小批量拿到货、会不会比价 |
| 擅长的产品 | 10 | 懂不懂这个品的成本和坑 |
| 可动用现金 | 25 | 货款立刻出去，回款要 45 天以上 |
| 每天时间 | 8 | 决定日常动作做得完不做得完 |
| 电脑基础 | 8 | 上架、看后台、改价都要用 |
| 兼职 / 全职 | 15 | 没有退路的全职风险最高 |
| **合计** | **100** | |

## 为什么资金给最高分

因为回款周期长。钱付给供应商是立刻的，回到自己卡上要 45–70 天（运输 13–35 天 + T+15 保护期 + 半月结 + 银行 1–3 天）。所以资金不足的真实问题不是"不够进货"，而是"撑不过这两个月"。

## 为什么兼职/全职不是"全职加分"

- 全职且有积蓄兜底：15 分（能全情投入，同时有钱撑）
- 兼职有主业：12 分（进度慢，但退路在）
- 打算辞职还没辞：6 分（准备进入高风险状态）
- 已辞职、无收入：0 分，并触发结论降档（生活费会和货款混在一起）

## 硬覆盖

不计分、优先级最高：

1. 无企业营业执照（个体户不算）/ 无同名收款账户 → 现在开不了店
2. 现金 < 5000 → 现在别投钱
3. 已辞职无收入 → 降一档 + 三条风控提示
