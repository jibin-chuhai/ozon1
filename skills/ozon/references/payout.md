# 回款周期

## 标准结算

**半月结（主流）**

- 当月 1–15 日完成收货的订单：最晚当月 25 日打款（电子等特殊品类可能延到 25–27 日）
- 当月 16 日–月底完成收货的订单：最晚次月 16 日打款

**周结（部分卖家）**

- 自然周结算，付款日为周结束后第 17 个自然日，遇节假日顺延
- 付款日后 2 个工作日内打款

## 跨境卖家

- 基础规则同半月结
- **首次结算需累计满 1000 美元 / 6500 元人民币**
  - 15 日前达标：当月 15–25 日回款
  - 未达标：累计至月底，次月 1–15 日回款
- **保护期**：订单完成后 T+15 天，防退货与欺诈，资金才转为可提现

## 全链路时间

```
订单完成 → T+15 保护期 → 生成结算单 → 打款 → 银行到账 1–3 天
```

加上运输 13–35 天，卖家从付货款到钱回卡：**约 45–70 天**。

平台侧从订单完成算：**约 15–20 天**。

## 查看方式

卖家后台 **Finance → Payments**，状态：生成中 / 待支付 / 已支付。

## 注意

- 节假日顺延
- 退款和佣金从结算中扣除
- 以后台结算单为准
