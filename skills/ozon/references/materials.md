# 开店材料与资质清单

## 必交

| 材料 | 要求 |
|---|---|
| 企业营业执照 | 自然人独资即可；**个体工商户不被接受** |
| 法人身份证 | 正反面照片，四角完整、字迹清晰 |
| 手机号 | 能接收短信验证码 |
| 邮箱 | 163 邮箱即可 |
| 收款账户（第三方） | 连连国际这类第三方收款即可，可直接绑定 OZON；回款可提现到法人本人的个人银行卡。**前提：账号法人必须与营业执照法人是同一人** |

## 关于收款，别被"必须对公"误导

OZON 跨境不需要专门开对公账户收款。用连连国际这类第三方收款账户绑定后，回款是走第三方再提到法人的个人银行卡。

卡的是**人**，不是账户类型：营业执照上的法人、第三方收款账号的法人，必须是同一个自然人。不是同一个人，就会在审核和提现两步卡住。

## 条件提交

| 材料 | 什么时候要 |
|---|---|
| EAC 认证 | 电子电器、儿童玩具、化妆品、食品接触、防护、汽配、灯具电池等受管类目 |
| 品牌授权 / 商标 | 做品牌类目时 |
| ИНН（俄罗斯税号） | 本地公司发货 |

## 驳回高频原因

1. 执照信息与第三方收款账户的注册信息不一致（最多），尤其是法人不是同一人
2. 受管类目缺 EAC 认证
3. 同主体重复注册
4. 商品信息含违禁品类

## 费用与周期口径

- 无保证金、无月租
- 审核一般 2–10 个工作日
- 以上均为参考，以后台当期要求为准
