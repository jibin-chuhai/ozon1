# 开店材料与资质清单

## 必交

| 材料 | 要求 |
|---|---|
| 企业营业执照 | 自然人独资即可；**个体工商户不被接受** |
| 法人身份证 | 正反面照片，四角完整、字迹清晰 |
| 手机号 | 能接收短信验证码 |
| 邮箱 | 163 邮箱即可 |
| 收款账户 | 户名与营业执照主体完全一致 |

## 条件提交

| 材料 | 什么时候要 |
|---|---|
| EAC 认证 | 电子电器、儿童玩具、化妆品、食品接触、防护、汽配、灯具电池等受管类目 |
| 品牌授权 / 商标 | 做品牌类目时 |
| ИНН（俄罗斯税号） | 本地公司发货 |

## 驳回高频原因

1. 公司英文名与收款账户户名不一致（最多）
2. 受管类目缺 EAC 认证
3. 同主体重复注册
4. 商品信息含违禁品类

## 费用与周期口径

- 无保证金、无月租
- 审核一般 2–10 个工作日
- 以上均为参考，以后台当期要求为准
